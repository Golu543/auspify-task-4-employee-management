# Task 4: Employee Management System
**Auspify Technologies — Software Development Internship**

## Overview
A full-stack Employee Management System built with React, Vite, Node.js, Express, and MySQL. It supports employee registration, profile management, department-wise filtering, real-time search, organizational headcount/payroll analytics, and CSV report exports.

## Setup Instructions
1. Import `database/schema.sql` into MySQL 8.0 (`auspify_employee_db`).
2. In `backend/`, configure `.env` and run `npm install && npm start` (runs on port `5003`).
3. In `frontend/`, run `npm install && npm run dev` (runs on port `5176`).
